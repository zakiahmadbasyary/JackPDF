# JackPDF

Aplikasi Windows desktop modern untuk mengolah dokumen PDF secara lokal menggunakan Python dan PySide6.

## Fitur Utama
1. **Merge PDF** - Menggabungkan beberapa PDF menjadi satu file.
2. **Split PDF** - Memisahkan halaman berdasarkan rentang atau halaman tertentu.
3. **Compress PDF** - Mengurangi ukuran PDF dengan preset kualitas.
4. **Convert to PNG** - Mengekspor halaman PDF menjadi gambar PNG.
5. **Crop PDF** - Memilih area halaman melalui preview.


## Cara Menjalankan
1. Pastikan virtual environment telah dibuat dan dependensi terpasang:
   ```powershell
   .venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
2. Jalankan aplikasi:
   ```powershell
   .venv\Scripts\python.exe main.py
   ```
